\section{Theory}
\label{sec:theory}

We write $R(\cdot)$ for the relevance assigned to a tensor, and consider
propagation rules that redistribute the relevance of an operation's output to
its inputs.

\begin{lemma}[Conservation by sum exchange]
\label{lem:sum-exchange}
Let $y_i = \sum_j w_{ij} v_j$ be any linear map, let $z_{ij} = w_{ij} v_j$ and
$z_i = \sum_j z_{ij}$. The rule
$R(v_j) = \sum_i \tfrac{z_{ij}}{z_i}\, R(y_i)$
satisfies $\sum_j R(v_j) = \sum_i R(y_i)$.
\end{lemma}

\begin{proof}
$\sum_j R(v_j)
= \sum_i \tfrac{R(y_i)}{z_i} \sum_j z_{ij}
= \sum_i R(y_i)$.
Conservation is one exchange of summation order. A stabilizer
$z_i + \varepsilon\,\mathrm{sign}(z_i)$ introduces a measurable leak of relative
size $|1 - z_i/(z_i+\varepsilon\,\mathrm{sign}(z_i))|$ and nothing else.
\end{proof}

\begin{lemma}[Permutations and coordinate embeddings are free]
\label{lem:permutations}
If the linear map has exactly one nonzero $z_{ij}$ per row $i$, the ratio in
Lemma~\ref{lem:sum-exchange} equals one, so the rule is exact: no leak, no
mixing. Window partitioning, cyclic shifts, un-concatenation, reshapes, and
padding-free regroupings are all of this form.
\end{lemma}

\begin{proposition}[Resolution reduction]
\label{prop:reduction}
Any resolution-reduction operator expressible as
$T(\mathcal{N}) = W\,\phi(\mathrm{concat}(x^{(1)},\dots,x^{(n)}))$,
where $\mathrm{concat}$ is a coordinate embedding and $\phi$ is a
conservation-preserving normalization, admits the rule of
Lemma~\ref{lem:sum-exchange} composed with Lemma~\ref{lem:permutations} and
conserves relevance up to the bias and stabilizer terms.
Corollaries, one proof: Swin patch merging ($n{=}4$, $\phi{=}\mathrm{LN}$),
strided-convolution patch embedding ($\phi=\mathrm{id}$, including the stems of
convolution-transformer hybrids), and PVT spatial-reduction attention (a
strided convolution on the key/value token grid).
\end{proposition}

\begin{theorem}[Conditional equivariance]
\label{thm:equivariance}
Let $\pi$ be a permutation of the input grid and $\Pi$ the family of induced
permutations on every intermediate token grid. If the forward pass commutes
with $\pi$, that is $f(\pi x) = f(x)$ for the pooled logits and
$F_\ell(\pi x) = \Pi_\ell F_\ell(x)$ for every intermediate representation,
then HiLRP relevance commutes with the same permutation:
$R(\pi x) = \pi R(x)$.
\end{theorem}

\begin{proof}
Every propagation rule in the framework is a function of the local activations
and shared weights only; no rule uses an absolute-position quantity. By the
premise, the activations at layer $\ell$ under input $\pi x$ are
$\Pi_\ell F_\ell(x)$. Applying any rule of Lemma~\ref{lem:sum-exchange} to
permuted activations yields the permuted relevance, because the rule's ratios
$z_{ij}/z_i$ are computed from the same values in permuted positions, and
permutation steps themselves propagate relevance exactly by
Lemma~\ref{lem:permutations}. The backward pass is a composition of such maps,
so the composition commutes with $\Pi$ layer by layer, and with $\pi$ at the
input.
\end{proof}

\begin{remark}[The premise is the interesting part]
\label{rem:premise}
Real hierarchical transformers rarely satisfy the premise exactly. Two
mechanisms break it for Swin: the shifted-window attention masks are anchored
to the image canvas, and the odd window grid (7) does not align with the even
merging grid (2), so no nontrivial input translation commutes with the full
hierarchy; the two grids align only at the full image period. On an idealized
cyclic variant whose grids align by design (window 4, merge 2, 16-token side,
no masks), the premise holds exactly and the measured relevance equivariance
error is below $10^{-8}$ in double precision.
\end{remark}

\begin{remark}[Partial symmetry transfer, measured]
\label{rem:transfer}
When the premise holds only approximately, the theorem degrades gracefully and
measurably. On pretrained Swin-T under cyclic window-multiple translations the
forward drifts by $7{\times}10^{-2}$ relative logit change, and HiLRP maps
remain consistent at Spearman $\rho \approx 0.90$, degrading to $0.52$ exactly
where the forward drift grows (unaligned shifts). A plain gradient map reaches
only $\rho \approx 0.41$ to $0.61$ at the same forward drift. The attribution
tracks the model, not the image, which is the behavior a faithful method
should exhibit under approximate symmetry.
\end{remark}
